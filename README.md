# 💗 Boyfriend Final Exam

**The ultimate relationship exam. Does he actually know his girlfriend, or has he just been guessing this whole time?**

🔗 **[Take the Boyfriend Final Exam](https://9cca3d76.boyfriend-final-exam.pages.dev/)**

Boyfriend Final Exam is a fun, shareable couples quiz website designed to test how well a boyfriend knows his girlfriend. Create an exam, customize questions, send your boyfriend his personal quiz link, and reveal the results when he finishes.

## ✨ Features

- **Classic Exam:** Create a quiz using the official question bank.
- **Custom Exam:** Write your own questions and answer options.
- **Flexible Quiz Length:** Choose 5, 10, 15, or 20 questions.
- **Shareable Quiz Link:** Send your boyfriend a link to take the exam.
- **Private Creator Link:** Check submissions and reveal results privately.
- **Automatic Scoring:** Calculate the score and generate a playful relationship verdict.
- **Privacy-Conscious Results:** The boyfriend's quiz page does not reveal the answer key or score before the creator reveals the results.
- **No Login Required for Quiz Takers:** Open the shared quiz link and take the exam.

## 🛠️ Tech Stack

- **Frontend:** React, Vite, JavaScript, CSS
- **Backend:** Cloudflare Pages Functions
- **Database:** Cloudflare D1
- **Deployment:** Cloudflare Pages
- **Version Control:** Git and GitHub

## 🚀 Try It Out

1. Visit the [live website](https://9cca3d76.boyfriend-final-exam.pages.dev/).
2. Create a classic or custom exam.
3. Choose your questions and set the correct answers.
4. Share the public quiz link with your boyfriend.
5. Open your private creator link to check the submission and reveal the results.

## 🎯 Project Goal

The goal was to build a playful, interactive website that couples can easily share, while keeping the answer key and creator results private until reveal.
